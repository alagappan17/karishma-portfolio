## Overview

A component modernization initiative for an investment portfolio portal, creating a more consistent experience across multiple personas and workflows.

## The challenge

- Components and interaction patterns had drifted across the portal.
- Different users needed different levels of detail from shared workflows.
- The product needed reusable, accessible patterns that could scale.

## Design goals

- Create a consistent component experience.
- Improve hierarchy for portfolio information and task states.
- Establish flexible patterns for future development.

## My role

- Audited existing components and mapped persona needs.
- Redesigned reusable UI patterns and system states.
- Produced prototypes and partnered through handoff and QA.

## Key screens and features

- Portfolio summaries, tables, filters, alerts, forms, and empty states.
- Shared patterns adapted for managers, analysts, operations, and leadership.

## Key learnings

Components need to account for behavior, accessibility, content, and edge cases, not only appearance.
